# Azras Welt

A small German learning and play world for a 7-year-old, built as a single web page. This repository only holds the
built game for GitHub Pages; nothing here collects data. Progress stays in the browser of the device that plays it.

## On an Android tablet

1. Open the game's link in **Chrome**.
2. Chrome menu (⋮) → **Add to Home screen** → **Install**. The icon opens the game full-screen, and it starts without
   internet after the first visit.
3. The cat and the neighbours talk with the tablet's own voice. Check **Settings → General management →
   Text-to-speech → Google** (on some tablets: *System → Languages → Text-to-speech*): under *Language* choose **Deutsch** and download the voice data.

## Backup

Progress lives only in Chrome on that tablet. Clearing Chrome's site data deletes it. Now and then: hold the small
⚙ in the top-left corner for 1 second (or click it 3 times) → **Parent area** → **Save a backup**. The file lands in
Downloads; **Restore from a backup** brings it back, on the same or a new tablet.
